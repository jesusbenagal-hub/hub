# Design system del hub

Las piezas con las que se construyen todas las apps del hub:

- **[Tokens](tokens)**: colores, tipografía, espaciado y radios de `@hub/tokens`.
- **[Componentes](componentes)**: los componentes de `@hub/ui` (shadcn/ui con Base UI y estilo Mira).
- **[Patrones](patrones)**: cómo se combinan en una pantalla real.
