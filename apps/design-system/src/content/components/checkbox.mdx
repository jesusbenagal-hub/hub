# Checkbox y Label

Una casilla para marcar o desmarcar. Siempre dentro de un `Label`, para que el
texto también la active y tenga nombre accesible.

<Example code={checkboxWithLabelCode}>
  <CheckboxWithLabel />
</Example>

El estado se expone en `data-checked`, así que el texto se puede tachar solo
con CSS: `has-checked:line-through` en el `Label`.

## Props de `Checkbox`

| Prop              | Qué hace                             |
| ----------------- | ------------------------------------ |
| `checked`         | Estado controlado                    |
| `defaultChecked`  | Estado inicial si no está controlado |
| `onCheckedChange` | Recibe el nuevo estado               |
| `disabled`        | La desactiva                         |
